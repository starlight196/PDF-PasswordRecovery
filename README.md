# PDF 密码恢复

面向 Windows 的本地 PDF 字典密码恢复工具。界面和计算核心均为 C# 编译程序，不依赖 Python；PDF 只解析一次，密码校验在内存中多线程执行。

## 功能

- 导入本地 PDF 和文本字典
- 自动识别 UTF-8、GB18030、UTF-16 字典编码
- 可配置工作线程及密码字节编码
- 实时显示尝试次数、速度、进度、耗时和当前候选词
- 支持暂停、继续和停止
- 本地密码管理：搜索、新增、编辑、删除及保存恢复结果
- 验证 PDF Standard Security `R2-R4` 的用户密码和所有者密码

## 构建

在 Windows 上运行：

```bat
build.cmd
```

生成文件位于 `bin\PdfPasswordRecovery.exe`。项目使用系统自带的 .NET Framework 4.8 编译器，无需安装 Python 或第三方运行库。

运行自测：

```bat
test.cmd
```

## 使用

1. 运行 `bin\PdfPasswordRecovery.exe`，选择要恢复的加密 PDF。
2. 导入文本字典；每行作为一个候选密码，空行代表空密码。
3. 按需选择字典编码、密码字节编码、线程数和空白处理方式。
4. 点击“开始”；界面会实时显示实际校验次数、速度、活动耗时和进度。
5. 恢复成功后可打开“密码管理”，选择明文 JSON 或 AES-256 密码库，再明确点击“保存当前结果”；程序不会自动保存密码。

## 密码管理

- 每次打开密码管理时可选择密码库文件和存储方式。默认明文路径为 `%LOCALAPPDATA%\PdfPasswordRecovery\passwords.json`，默认加密路径为 `%LOCALAPPDATA%\PdfPasswordRecovery\passwords.aesvault`。
- 明文 JSON 会直接保存 PDF 密码，任何能读取该文件的人都能看到内容，仅用于用户明确接受该风险的场景。
- AES-256 模式使用用户设置的密码，通过 PBKDF2-HMAC-SHA256 派生独立的加密和认证密钥，再使用 AES-256-CBC 与 HMAC-SHA256 加密并校验完整性。
- AES 密码只在本次密码管理窗口中使用，不写入磁盘，也无法由程序找回。密码错误或文件被篡改时，程序会拒绝读取和覆盖。
- 两种模式均采用同目录临时文件、强制落盘和原子替换，避免进程终止或断电时留下半个密码库。
- 旧版 `%LOCALAPPDATA%\PdfPasswordRecovery\passwords.vault` 是 Windows DPAPI 格式；当前版本会明确拒绝该格式，不会自动解密、迁移或覆盖。
- 管理窗口默认隐藏密码；可搜索 PDF 路径、类型和备注，也可新增、编辑、复制或删除记录。空密码会作为独立的有效记录处理。
- 从管理窗口复制的密码会在 30 秒后尝试从剪贴板清除；仅当剪贴板内容仍是该密码时才会清除。
- 显示、复制密码或另存结果都会产生明文，请只在受信任的账户和设备上使用。

## 支持范围

- 支持 PDF Standard Security Handler `R2-R4` 的用户密码和所有者密码。
- 支持经典 xref 及其增量更新；不支持 xref stream、object stream 或混合 xref。
- 不支持 PDF `R5/R6`、Office 文档或 ZIP/RAR 等压缩文件。
- 单个 PDF 最大 2 GB；解析时会将 PDF 读入内存。

## 使用边界

只处理你有权访问的本地 PDF。程序不连接网络，也不会上传 PDF、字典或恢复结果。

密码恢复、多线程密码校验和本地加密文件写入可能触发安全软件的行为监控。不要因此关闭杀毒软件或排除整个目录；应先核对源码、构建哈希和安全软件的完整事件详情。
